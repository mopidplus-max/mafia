# Реле для игры на расстоянии

Папка `relay/` — отдельный проект для **Vercel**. Он проксирует запросы
игроков к телефону ведущего, поэтому все могут играть из разных сетей.

Как это работает:

1. Игрок открывает сайт реле и вводит код комнаты.
2. Сайт ставит его HTTP-запрос в очередь в Upstash Redis.
3. Телефон ведущего каждые ~0.7 с забирает очередь с Vercel, выполняет
   запросы у себя (локальный сервер на `127.0.0.1:8080`) и отправляет ответы.
4. Игрок забирает ответ и продолжает игру.

Белый IP и проброс портов не нужны — телефон ведущего сам выходит в интернет.

## Что понадобится

- Аккаунт [Vercel](https://vercel.com) (бесплатного плана хватает).
- База [Upstash Redis](https://upstash.com) — подключается в Vercel через
  Marketplace → Upstash.

## Деплой

### Вариант 1: через сайт Vercel

1. Загрузите репозиторий на GitHub.
2. В Vercel: **Add New → Project** → выберите репозиторий.
3. **Root Directory** укажите `relay`.
4. В **Storage** подключите Upstash Redis (или создайте базу в Upstash и
   скопируйте REST-переменные).
5. Убедитесь, что в переменных окружения есть:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
6. **Deploy**.

### Вариант 2: через CLI

```bash
cd relay
npm install
npx vercel            # первый деплой, привязка проекта
npx vercel env add UPSTASH_REDIS_REST_URL
npx vercel env add UPSTASH_REDIS_REST_TOKEN
npx vercel --prod
```

## Настройка в приложении

1. Создайте комнату в приложении «Мафия».
2. В лобби откройте карточку **«Игра на расстоянии»**.
3. Введите адрес реле, например `https://mafia-relay.vercel.app`.
4. Придумайте **код комнаты** (до 8 латинских букв и цифр), например `DANYA7`.
5. Включите переключатель.

Игроки открывают адрес реле, вводят тот же код — и попадают в комнату.

> Код комнаты — это общий секрет. Кто знает код, тот может зайти в лобби,
> если там есть места. Не публикуйте его.

## API реле

| Метод | Путь | Кто вызывает | Что делает |
|---|---|---|---|
| POST | `/api/relay/enqueue` | сайт игрока | ставит запрос в очередь |
| GET | `/api/relay/result?id=…` | сайт игрока | забирает ответ |
| POST | `/api/relay/poll` | телефон ведущего | забирает пачку запросов |
| POST | `/api/relay/reply` | телефон ведущего | отправляет ответы |
| GET | `/api/relay/health` | кто угодно | проверка живости |

## Обновление веб-клиента

Сайт реле использует тот же `app.js` и `style.css`, что и локальная комната.
После правок в `app/src/main/assets/web/` выполните:

```bash
./sync-web.sh
```

и задеплойте снова.

## Ограничения

- Бесплатный Vercel ограничивает время выполнения функции, поэтому ответы
  забираются короткими запросами, а не одним долгим соединением.
- Если телефон ведущего ушёл в сон, ответов нет — игра ждёт.
- Upstash хранит очередь 15 минут, отдельные запросы — 2 минуты.
