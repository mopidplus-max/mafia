# Мафия по локальной сети

Android-приложение для игры в «Мафию» без интернета: один телефон работает
ведущим и раздаёт Wi-Fi (или точку доступа), остальные подключаются к нему.
Android-игроки заходят через приложение, iPhone — через сайт, который поднимает
телефон ведущего.

- Kotlin + Jetpack Compose, Material 3, тёмная тема.
- Встроенный HTTP-сервер (NanoHTTPD) на порту `8080`.
- Логика игры портирована из `new.py`: 14 ролей, ночные ходы, голосование,
  проверки победы.

## Сборка

Нужен Android Studio (Koala или новее) либо JDK 17 + Android SDK 35.

```bash
cd mafia-lan
./gradlew assembleDebug      # APK: app/build/outputs/apk/debug/app-debug.apk
```

В Android Studio: **Open** → выбрать папку `mafia-lan` → дождаться синхронизации
Gradle → **Run**.

Gradle-обёртка (8.9) лежит в проекте, `local.properties` с путём к SDK создаётся
автоматически при первой синхронизации.

## Как играть

1. Ведущий нажимает **«Создать комнату»**: название, пароль (по желанию),
   набор возможных ролей, лимит участников (`0` — без ограничения).
2. Ведущий включает **точку доступа** (или все садятся в один Wi-Fi). В карточке
   комнаты показан адрес вида `http://192.168.43.1:8080`.
3. Android-игроки: **«Подключиться»** → адрес ведущего → имя → пароль.
4. iPhone: тот же адрес открыть в **Safari**, ввести имя и пароль.
5. Ведущий видит список участников с иконками устройств (Android / iPhone /
   браузер) и нажимает **«Начать игру»** при 4+ игроках.

Ведущий не играет: он видит роли всех участников и ведёт партию кнопкой
**«Далее»** (пропустить отсчёт, следующий ночной ход, рассвет, голосование,
следующая ночь).

### Ход партии

| Этап | Что происходит |
|---|---|
| Раздача | Игроки 10 секунд видят свою роль, ведущий — роли всех |
| Ночь | «Город засыпает…», затем по очереди просыпаются роли |
| Ночь | Наркоман → Красотка → Мафия → Доктор → Комиссар → Ангел → Ведьма → Маньяк |
| Утро | Итоги ночи: кто погиб, кого спасли, кого воскресили |
| День | 60 секунд обсуждения (снайпер может выстрелить) |
| Голосование | По очереди, у каждого 30 секунд; голос мэра считается за два |
| Итог | Изгнание или ничья голосов, проверка победы |

Таймеры: 10 с старт, 45 с ночной ход, 5 с информационные шаги, 60 с обсуждение,
30 с на голос. Ведущий может пропустить любой шаг вручную.

### Роли

Мафия (🔴), Дон (👑), Адвокат (⚖️), Доктор (💚), Комиссар (🔵), Красотка (💋),
Ангел (😇), Мэр (🏛️), Шут (🃏), Ведьма (🧙), Наркоман (💊), Маньяк (🔪),
Снайпер (🎯), Мирный (⬜).

Колода собирается так: мафия обязательна (примерно треть состава, Дон — только
при 8+ игроках), спецроли выбираются случайно из отмеченных ведущим, остальные
слоты — мирные.

Победы: мирные — когда нет мафии и маньяка; мафия — когда её не меньше, чем
мирных; маньяк — когда остаётся последним; шут — если его изгнали голосованием.

## Веб-клиент для iPhone

Лежит в `app/src/main/assets/web/` (`index.html`, `style.css`, `app.js`) и
раздаётся тем же сервером:

- `/` — страница игры;
- `/assets/*` — статика;
- `/api/room`, `/api/join`, `/api/leave`, `/api/state`, `/api/action` — JSON API.

Android-клиент ходит в те же эндпоинты, состояние опрашивается раз в секунду.
Сессия веб-клиента хранится в `localStorage` и привязана к адресу комнаты.

## Ограничения

- Только локальная сеть, без TLS и без выхода в интернет.
- Приложение ведущего должно быть открыто: сервер живёт, пока жив процесс.
- Если ведущий свернёт приложение, Android может приостановить сервер.
- Игра не переживает перезапуск приложения (нет сохранения партии).
- iOS-игроки не могут переподключиться к идущей игре: вход разрешён только в лобби.
- Отключившийся во время игры игрок остаётся в составе, его ночные ходы и голос
  пропускаются автоматически; в лобби его можно удалить, просто выйдя из комнаты.

```
app/src/main/java/com/danya/mafia/
  game/     GameEngine.kt (состояния партии), Roles.kt, Models.kt (DTO + JSON)
  server/   GameServer.kt (HTTP), WebAssets.kt, LocalNetwork.kt
  net/      ApiClient.kt (клиент к комнате)
  ui/       экраны Compose, AppViewModel.kt, Components.kt
app/src/main/assets/web/   клиент для iPhone
```
